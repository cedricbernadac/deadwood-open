## Sources

| Files | How they were made |
| --- | --- |
| `public/levels/*.glb` (cabin surroundings, supermarket, hospital, funfair) | Built in Blender from scripts written for this game, with original textures |
| `public/frisson/*.glb` (heads, bodies, survivors, weapons, pickups, markers, cabin dressing) | Built in Blender for this game; the author chose among proposals |
| `public/hud-silhouettes/` | Rendered from the game's own weapon geometry |
| `public/bonus-icons/`, `assets/bonus-icons/` | Generated with an AI image model for this game, then resized; prompts in `assets/bonus-icons/prompts.json` |
| `public/audio/*.mp3` (music: Night Watch, Colossus, Last Stand, Tactical Resolve A/B, Covert Ostinato A/B, Night Resolve A/B) | Generated by the author with Suno (paid plan) |
| `public/audio/*.wav` (pistol, SMG, shotgun, heavy rifle, assault fire, flamethrower, rocket launcher, grenade, katana, shotgun click, brute and boss roars) | Generated by the author with ElevenLabs (paid plan), trimmed and normalised |

Other sounds in the game are synthesised in code (`public/audio.js`). No third-party model, texture or sound library is included.
